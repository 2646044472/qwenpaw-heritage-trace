# Heritage Trace Landing Page Redesign

## 目標

為大學評審與現場展示提供一個能在十秒內理解的產品入口。首頁先證明 Heritage Trace 是由政府、商戶與旅客三個介面組成的同一套文化商戶系統，再引導使用者從 Government 開始完整旅程。

## 核心敘事

首屏以繁體中文說明產品能力：一套共享系統，讓政府發現需要關注的文化商戶、讓商戶把證據轉化為行動、讓旅客透過地圖重新探索澳門文化。

全頁沿用 README 的循環：

> 被忽略 → 被發現 → 被理解 → 被活化 → 被重新看見

除 Heritage Trace、Pawly、Paw-Insight 等產品名稱外，介面文案使用繁體中文。不使用 Demo、Live Demo 或英文說明句。

## 頁面結構

### 1. 首屏：產品先行

- 左側：Heritage Trace 品牌、簡潔繁中主張、一段不超過兩行的產品說明，以及唯一主按鈕「開始旅程」。
- 右側／下方：使用 `docs/images/heritage-trace-overview.png` 作為大型產品主視覺。
- 主視覺直接呈現政府、商戶與旅客三端，避免額外裝置 mockup、浮動卡片或裝飾插圖。
- 主按鈕前往 `/government?shop=lei-kei-001`。

### 2. 三端旅程

- 以一條橫向流程呈現「政府發現 → 商戶行動 → 旅客探索」。
- 每一步只包含序號、角色名稱與一句繁中說明。
- 桌面版為單線流程，手機版改為垂直順序。
- 不使用三張獨立產品卡，強調三者共享同一份商戶身份與已核實文化資料。

### 3. 共同資料核心

- 用簡潔排版說明文化來源經 QwenPaw Workflow 整理與核實，再由 Paw-Insight 結合曝光與情緒訊號，傳遞至三個介面。
- 以一個克制的 verified record artifact 作為證據，不展示完整後台 UI。
- 清楚說明只有符合公開規則的資料會進入商戶與旅客介面。

### 4. 結尾行動

- 深墨綠背景，主句為「從一間店開始。」
- 單一按鈕「開始旅程」，再次前往 Government。
- 輔助文字顯示「政府發現 → 商戶行動 → 旅客探索」。

## 視覺系統

- 米白作為主要背景，深墨綠作為文字與主色，金色只用於核實狀態與細小重點。
- 使用現有語意色彩 token，不新增任意色碼。
- 字體以現有 Heritage display 字體承擔文化氣質，Geist Sans 負責介面與內文，Geist Mono 只用於序號和年份。
- 以排版、留白、細邊框建立層級；避免大圓角、重陰影、玻璃效果、漸層與巢狀卡片。
- 一屏只保留一個主要焦點。動畫限於淡入、圖片 reveal 與細線延伸，並尊重 reduced-motion。

## 響應式與可用性

- 首屏在桌面保持文字與產品圖清楚並列；手機版先閱讀主張，再看完整產品圖。
- 圖片維持原始比例，不裁切產品介面中的關鍵資訊。
- 所有連結具備可見 focus 狀態；圖片提供繁中替代文字。
- 導覽維持精簡，不新增不必要的頁內選單。

## 驗收標準

- 裁判在首屏即可辨認 Government、Merchant / Pawly、Hunter 是同一套系統的三個介面。
- 全頁主要敘事為繁體中文，沒有 Demo 字眼。
- overview 圖成為首屏唯一主視覺，原本的建築線稿不再出現。
- CTA 能開啟指定 Government 商戶旅程。
- 桌面與手機版沒有水平溢出、文字遮擋或圖片裁切。
- 型別檢查、相關測試與 production build 完成，並以瀏覽器檢查首頁內容、錯誤 overlay 與主要導覽。
