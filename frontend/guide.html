WORKFLOW

日常工作流

每一步都有明確交接
  1. 01

    選擇項目

    從左欄選現有個案，或建立一個新項目；先確認街區與資料範圍。

    進入工作台
  2. 02

    整理來源

    點「新增來源」，填入名稱、類型、證據摘錄和權利狀態；不要把未授權內容標為公開。

    前往資料歸檔
  3. 03

    生成候選

    有來源後才可執行 Qwen 建檔。每條候選都要帶來源編號，尚未等於真實或可公開。

    查看 Qwen 建檔
  4. 04

    人工核驗

    在核驗頁對照原文並記錄理由：可公開、待確認或僅內部，不能由模型自行決定。

    進入核驗審核
  5. 05

    發布與回訪

    先執行 Coordinator，再查看地圖與發布閘門；通過後才建立 G / B / C 成品。

    查看發布與活化

QWENPAW DESKTOP

模型設定

  1. 開啟 QwenPaw Desktop 的 Settings → Models。
  2. 選擇 Aliyun Coding Plan (China)，在應用程式內保存自己的 API Key。
  3. 測試連線後，選擇要使用的模型。

Desktop 的個人模型設定不會寫入本專案、Git 或 Docker `.env`。

LOCAL ACCOUNT

本機管理端帳戶

帳戶密碼只保存為不可逆的 scrypt 雜湊，無法從資料庫讀回。全新環境由啟動者在本機設定初始密碼。

同學各自使用 `.env.example` 建立自己的 `.env`；不要共用、截圖或提交密碼與 Key。

TEAM / CLOUD

協作與部署

同學電腦可用 Docker Compose 在本機回環地址啟動；Ubuntu 雲端以 systemd 和 Nginx 部署，API 維持只監聽 127.0.0.1。
